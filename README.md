# Kairacure Patient Web Application (`kairacure-web`)

Patient-facing medical travel portal for Kairacure (`https://kairacure.com`).

## Key Features
- **Treatment Cost Estimator**: Interactive treatment planning & cost calculator.
- **Hospital & Doctor Search**: Comprehensive search with accredited hospital profiles & specialists.
- **AI Medical Assistant**: Interactive guidance for medical travel preparation.
- **Patient Portal**: Secure login, treatment status tracking, and inquiry management.

## Quick Start
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
